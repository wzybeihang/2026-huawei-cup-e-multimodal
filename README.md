本仓库不包含比赛官方数据、原始音视频、特征数组、标签、测试集预测、论文或模型权重。运行代码前，必须确认数据和预训练模型的获取与使用许可，并自行从获准来源准备输入。代码是否适用于其他数据目录，需由使用者根据各脚本参数调整。

## 代码完整性与运行输入

这里收齐的是三个整理版 `code/` 目录中的 27 个 Python 脚本，并非完整可复现实验包。问题1的 `pipeline.py` 还需要未随仓库提供的 `config/pipeline.json`、获准数据和预训练模型；问题2还需要获准的 `aligned_50.pkl`、BERT 文件以及由 `prepare_data.py` 生成的缓存；问题3还需要附件2/附件4数据和问题2输出中的 `matrix_no_aug/best.pt`、`scaler.npz`。这些缺项没有因为“收齐脚本”而自动解决。取得授权并按各脚本参数准备输入后，仍需补充逐题运行说明并实际验证，才能称为可复现项目。
